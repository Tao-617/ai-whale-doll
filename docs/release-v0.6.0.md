小鲸 0.6.0 测试版，首次提供可下载的 Mac 与 Windows 包。

### 下载与安装

- **Mac M 系列 / macOS 14+**：下载 `Xiaojing-0.6.0-macOS-arm64.dmg`，打开后将 Xiaojing 拖入 Applications。不支持 Intel Mac。
- **Windows 10/11 x64**：下载 `Xiaojing-0.6.0-Windows-x64.exe`，直接运行。此包在 Mac 上交叉构建，尚未在真实 Windows 桌面验收。
- 无须安装 Node 或 Python。请同时阅读 `使用说明.txt`；`SHA256SUMS.txt` 提供安装包的 SHA-256 校验值。GitHub 自动生成的 Source code 文件是源码，不是安装包。

### 本版行为

随机游走沿四周边缘左右走、上下爬；截图后的主动移动可以暂时到关注内容旁说话，气泡结束后回边缘。修复了静止鼠标误触导致停步，以及切换大小后留在中央的问题。保留拖拽、倒立、转晕、小动作和本地闲聊。

### 使用前须知

安装包尚未做 Apple 公证或 Windows 商业代码签名，首次启动可能被系统拦截。Mac 已在本机启动验证；Windows 的透明窗口、托盘、不同 DPI 和截图兼容性仍需实机试用。

本地桌宠功能不需要密钥。AI 聊天和截图点评需要使用者配置自己的 Anthropic Messages 兼容服务及 API Key，服务商可能收费；没有内置开发者密钥。观察默认暂停、允许名单默认空，Mac 还需要录屏权限。只查询键鼠活动间隔，不记录具体按键；截图发送到使用者配置的服务，不保存到本地。连接结果不确定时暂停，不自动重试。
